# Defer audio and target desktop first

MVP 1 will ship without sound and will target desktop and laptop layouts first, with a usable tablet-width fallback. The retro desktop shell is the core product shape, and silent verified play is a stronger milestone than adding audio before the game feel is proven.

**Consequences**

The first implementation should not spend complexity on music, sound effects, mute controls, or mobile-phone adaptation. Layout work should protect the desktop pane-and-tile experience before optimizing smaller screens.
