# Keep the first Town thin but functional

The first Town will support rest, buying and selling basic supplies, Save Slot management, entering The Keep, and reading the Journal. This keeps the safe hub real without spending the first implementation on complex NPC dialogue before the dungeon loop exists.

**Consequences**

Town screens should be usable rather than decorative. NPC conversations, elaborate shops, and branching dialogue can wait until the core run loop has browser evidence.
