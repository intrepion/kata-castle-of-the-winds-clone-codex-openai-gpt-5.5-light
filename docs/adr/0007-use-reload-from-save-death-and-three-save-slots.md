# Use reload-from-save death and three Save Slots

Adventurer death will return the player to reload-from-save flow for the first version, and the game will provide three browser-local Save Slots. This keeps testing and exploration humane while preserving a desktop-era save model.

**Considered Options**

- Permadeath.
- Reload from save.
- Rescue in Town with penalties.

**Consequences**

The game should make saving, continuing, overwriting, and death recovery explicit. Permadeath can be introduced later as an optional mode once the core loop is stable.
