# Build MVP 1 as one verified implementation slice

The design grilling is complete enough to begin implementation, and MVP 1 will be built as one complete vertical slice before the playable game is committed. The documentation history already records the decision trail, so the next valuable boundary is verified browser play rather than more planning commits.

**Consequences**

Implementation should proceed against the documented contract and resolve smaller tactical choices locally unless they contradict the glossary or ADRs. The playable commit should follow syntax checks, browser verification, push, and SHA alignment.
