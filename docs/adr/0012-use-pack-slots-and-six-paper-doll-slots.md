# Use Pack Slots and six Paper Doll slots

Carrying capacity will be slot-based rather than weight-based, and the Paper Doll will use Main Hand, Off Hand, head, body, ring, and Charm slots. This keeps item decisions visible in a compact desktop UI while leaving room for meaningful loot identity.

**Considered Options**

- Slot-based carrying.
- Weight-based carrying.
- A larger simulation-style equipment layout.

**Consequences**

Items should communicate their slot and value quickly. The game should avoid hidden encumbrance math in the first version.
