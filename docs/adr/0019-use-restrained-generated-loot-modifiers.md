# Use restrained generated loot modifiers

Generated loot will use a base item plus at most one Modifier, such as `Keen Iron Dirk` or `Windglass Ring`. This gives treasure personality without creating an itemization swamp before combat, Pack, and Paper Doll decisions are proven.

**Consequences**

Item text and mechanics should remain readable at a glance. The first version should prefer fewer meaningful modifiers over broad rarity ladders.
