# Make the Windglass Lens the first win objective

The first four-floor dungeon arc will end by recovering the Windglass Lens from the sealed fourth floor and returning it to Town. This gives the run a concrete objective beyond killing a boss and reinforces the game's original wind-and-glass identity.

**Consequences**

The final floor needs a sealed objective moment, a return condition, and a win flow in Town. Bosses can exist, but they are not the whole definition of victory.
