# Use a retro desktop RPG shell

Windglass Keep will present itself as a lost Windows-style desktop RPG: tile map, menu bar, bordered panes, status strips, log, paper doll, pack, journal, and save-slot dialogs. This is a deliberate fidelity choice because Castle of the Winds' identity comes as much from its native desktop interaction model as from its dungeon rules.

**Considered Options**

- A faithful retro desktop shell with mouse-first interaction and keyboard shortcuts.
- A partial retro visual treatment with a more modern browser game layout.
- A modern fullscreen roguelike interface.

**Consequences**

Controls, layout, and terminology should favor inspectable desktop RPG actions over terminal roguelike conventions. The UI can be polished for today, but it should not hide the menu-driven, mouse-readable character of the source inspiration.
