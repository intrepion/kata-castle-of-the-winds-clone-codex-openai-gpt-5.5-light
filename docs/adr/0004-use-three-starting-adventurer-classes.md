# Use three starting Adventurer classes

Windglass Keep will start with three Adventurer classes: Sentinel, Arcanist, and Wayfarer. This creates meaningful replay and tactical contrast without making character creation or balance the center of the first implementation.

**Considered Options**

- One balanced class.
- Three archetypal classes.
- Custom point allocation.

**Consequences**

Class identity should change equipment, survivability, spell access, or dungeon tactics in visible ways. The classes should remain simple enough that a new game can begin quickly.
