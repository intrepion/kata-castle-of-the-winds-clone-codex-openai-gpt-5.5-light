# Use 28 by 18 Dungeon Floors

Each Dungeon Floor will use a `28x18` Tile grid. This gives enough space for rooms, corridors, encounters, and fog-of-war planning while fitting beside the desktop panes without making the primary game surface scroll.

**Consequences**

Generation, visibility, and layout should tune around this fixed playfield. The first version should improve density and pacing inside the grid before increasing map size.
