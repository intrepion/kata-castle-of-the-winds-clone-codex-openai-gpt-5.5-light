# Require browser evidence for MVP completion

MVP completion requires exercising the real browser path: load the page, start as Sentinel, enter Town, enter The Keep, advance a dungeon turn, fight or inspect an encounter, save, reload, and confirm no console errors. Static syntax checks are useful, but they are not proof that the game exists as an interaction.

**Consequences**

Verification work should include browser automation or an equivalent live browser pass. Completion notes must describe the actual interaction path tested, especially save and reload behavior.
