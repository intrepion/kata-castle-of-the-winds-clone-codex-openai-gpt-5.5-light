# Start with six Spells

Windglass Keep will begin with six Spells: Spark, Mend, Ward, Reveal, Blink, and Glassbind. This gives the first version damage, recovery, protection, detection, escape, and control without requiring a large spellbook.

**Consequences**

Spell design should cover distinct tactical jobs before adding variants. Each Adventurer class can interact with the set differently, but the shared spell vocabulary should stay small enough to learn quickly.
